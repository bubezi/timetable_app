Trading Journal

Log trades, screenshots, P&L and how you were feeling when you took them. Everything is saved locally in this browser — no backend, no login. Export to JSON any time as a backup.

MT5 doesn't let a plain web page connect to it directly. To bring trades in: in the MT5 terminal, go to the History tab, right-click → Report → Save as Report, open it in Excel and re-save as CSV, then use "Import MT5 CSV" above. It maps Symbol / Type / Volume / Price / Price(close) / Profit columns automatically where it can find them.
