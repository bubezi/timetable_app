How to use

  • Edit any cell directly.
  • Click Save to keep it in your browser.
  • Use Export JSON to back it up or move it to another device.
  • Use Print / PDF for a clean printable sheet.

Hosting

  • Works by double-clicking the HTML file locally.
  • Also works on Nginx, GitHub Pages, Netlify, Cloudflare Pages, or any static subdomain.
  • No database needed unless you later want sync across devices.

Reality check

This is intentionally simple. It stays well under your 2-page / 2000-line limit. Fancy syncing, accounts, reminders, and analytics are where complexity grows teeth.

Saved locally in your browser. Clear site data and it forgets everything — like a goldfish with developer privileges.
